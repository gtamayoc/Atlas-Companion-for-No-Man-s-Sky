# Roadmap de Atlas NMS

## Fases del Desarrollo

- [ ] **Fase 1: Inicialización y Arquitectura Base** (En progreso)
  - Configurar repositorio, arquitectura KMP y almacenamiento local eficiente.
- [ ] **Fase 2: Mocking NMSCE y Sincronización** 
  - Crear modelo de datos, mock local y ViewModels reactivos (`StateFlow`).
- [ ] **Fase 3: Sistema de Diseño Centralizado**
  - Implementar paleta de colores, tipografía (Space Grotesk, Inter, Space Mono).
  - Componentes: BottomNav, Cards fluidas, renderización de Glifos, ScanFab.
- [ ] **Fase 4: Integración UI/Data**
  - Conectar UI centralizada a los flujos del Mock NMSCE.
- [ ] **Fase 5: Validaciones y Pruebas Iniciales**
  - Validación del "HUD" en Android.
